# Пример универсального вложенного SDLC

Этот пример намеренно мал и нейтрален к продукту. Он моделирует внешний цикл
delivery, содержащий циклы requirements, implementation, testing, release и
operation. Testing вызывает цикл runtime-scenario.

Generic SDLC — пример binding Concord Loom, а не граница самого продукта.
Принятая self-binding репозитория использует другую, предметно-нейтральную
структуру.

Каталоги создаются на разных этапах:

- `inspection/` содержит примеры наблюдаемого графа, вопросов, решений и
  принятого графа;
- `runtime/` содержит принятую registry циклов, binding, candidate manifest,
  run card и примеры evidence.

Главное различие видно и в данных, и в Atlas:

- containment — конечный DAG;
- локальные переходы состояния могут возвращаться назад только при конечном
  бюджете и явном терминальном пути исчерпания.
