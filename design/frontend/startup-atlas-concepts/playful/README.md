# Playful startup Atlas concepts

This is the second visual round for Concord Loom Atlas. It explores a warmer,
more informal product voice without turning the interface into an RPG.

Open [`index.html`](index.html) through a local HTTP server. Every direction:

- reads the real `framework/concordloom/catalog.json`;
- lets the viewer switch accepted versions;
- supports drilldown, breadcrumbs, browser history, and `Escape`;
- reflows for desktop, tablet, and mobile;
- uses the same graph engine and differs only in visual direction.

The five directions are:

1. **Signal Cards**: crisp cobalt cards and direct hierarchy.
2. **Paper Trail**: a warm ribbon that reads like a clear trail.
3. **Soft Orbit**: calm geometry around the active cycle.
4. **Patch Panel**: a dark modular workspace without hacker styling.
5. **Odd Grid**: disciplined structure with a less formal face.

These files are disposable design explorations. Accepted cycle data remains the
source of truth; the Atlas is only its projection.
