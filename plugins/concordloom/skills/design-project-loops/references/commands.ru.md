# Карта команд Concord Loom v0.1

Используйте этот справочник только после проверки встроенной программы запуска
и справки нужной подкоманды. Флаги команд — версионированные контракты, поэтому
не придумывайте параметры.

## Как запустить команду

Из каталога установленной инструкции агента запускайте команды так:

```bash
python3 scripts/concordloom_cli.py <command> ...
```

Программа запуска сначала ищет точную исходную поставку Concord Loom v0.1 в том
же репозитории. Если плагин установлен без дерева исходников, она использует
установленную команду `concordloom`. Проверить выбранный путь без запуска
команды проекта можно так:

```bash
python3 scripts/concordloom_cli.py --resolve
```

Если Concord Loom не установлен, программа запуска и предварительная проверка
выводят план установки `install_plan` для соответствующего выпуска v0.1. План
сначала выбирает `pipx`, затем `uv tool`, а после них — отдельное виртуальное
окружение вне целевого репозитория. Покажите план оператору и получите
разрешение до выполнения команд. Затем снова запустите `--resolve`.

Не используйте системный `pip`, `--break-system-packages`, незакреплённый пакет
или исходники, скопированные в целевой репозиторий. Поле `install_argv`
сохранено для совместимости и содержит только первую команду; используйте
полный `install_plan`.

## Новый репозиторий

Отсутствие конфигурации циклов `binding` не означает ошибку командной строки.
Предварительная проверка сообщает `mode=bootstrap-discovery`. Храните результаты
во временном каталоге и используйте только `inspect` и `questions`, пока не
подготовлен пакет первичной настройки `bootstrap packet`.

До принятия точных записей первой конфигурации оператором запрещены:

- изменение репозитория;
- заявления о полномочиях;
- доступ к сети и внешние изменения;
- разрешение карточки запуска `run card`;
- включение конфигурации `binding`.

| Этап | Семейство команд | Требуемый результат |
|---|---|---|
| Наблюдение | `concordloom inspect` | Граф со сведениями `observed` и `inferred`, привязанный к версии `revision` |
| Вопросы | `concordloom questions` | Ранжированные вопросы и описание изменений ответа `answer delta` |
| Решение | `concordloom decide` | Решение с участником `actor` и обоснованием `rationale`, записанное без изменения прежних решений |
| Принятие | `concordloom accept` | Принятый граф либо блокирующая ошибка |
| Предложение | `concordloom propose` | Изменение дизайна циклов `delta`, подготовленное для проверки |
| Компиляция | `concordloom compile` | Реестр `registry` и предложение конфигурации `binding proposal`, которое не даёт себе полномочий |
| Включение | `concordloom activate` | Конфигурация `binding`, принятая из предложения с точным хешем `proposal digest` |
| Проверка | `concordloom validate` | Проверка схем и согласованности артефактов |
| Фиксация результата | `concordloom candidate` | Канонический манифест проверяемой версии `candidate manifest` и хеш `digest` |
| Каталог | `concordloom catalog` | Новая запись в цепочке действующих конфигураций без переписывания истории |
| Выполнение | `concordloom run` | Жизненный цикл управляемой карточки запуска `run card` |
| Атлас | `concordloom atlas` | Детерминированное автономное HTML-представление |
| Эволюция | `concordloom evolve` | Предложение следующей версии без её включения |

Генератор Атласа поддерживает `--locale en` и `--locale ru`. При генерации и
проверке с `--check` передавайте язык, выбранный оператором; не полагайтесь на
язык по умолчанию. Выбор меняет только человекочитаемое представление, но не
каноническую конфигурацию `binding` и не машинные данные запуска `run data`.

Семейство `run` содержит `new`, `authorize`, `attempt`, `evidence`, `guard` и
`complete`. Перед использованием всегда открывайте вложенную справку.
Запускайте `guard` до чтения или изменения файлов в области задачи и
перечисляйте каждый предполагаемый путь. Запись попытки содержит сведения о
фактически использованных модели и поставщике, выводе данных, доступе к сети,
внешних изменениях, длительности и стоимости. Для записи доказательств
`evidence` и завершения нужен `--payload-root`: он позволяет сверить заявленный
хеш данных `payload digest` с реальными байтами.

Если `--help` отличается от этой карты, остановитесь и сообщите о несовпадении
версии. Не переходите к ручному редактированию канонических артефактов.

Команды и флаги в этом русском справочнике намеренно не переводятся. Русский
текст не создаёт отдельного контракта CLI и не меняет границы полномочий.
