# Concord Loom product truth

[Русская версия](ru/PRODUCT.md)

Status: **normative**

Concord Loom discovers, negotiates, runs, visualizes, and evolves bounded
systems of development loops. It is engine-, provider-, and repository-layout
agnostic.

## Primary user path

1. Install Concord Loom.
2. Inspect a project and generate its Atlas.
3. Correct or approve the proposed map.
4. Keep the Atlas current as the project changes.
5. Review and explicitly approve any proposed evolution.

Formal graphs, policies, evidence records, and authority checks support this
path. They should not become onboarding work for a newcomer.

## Everyday task path

1. Describe the desired change in ordinary language.
2. Review the proposed route through the accepted Atlas.
3. Correct the route or confirm it for this task.
4. Run the confirmed plan and compare the plan with what actually happened.

A route preview is a proposal, not permission to execute. It is pinned to the
active rules and exact candidate, contains no raw request text, and becomes
stale when those inputs change. Confirming one route does not change the
accepted Atlas. A lasting change still goes through the separate evolution
path.

## Users

- A project owner who wants an understandable map of how work gets done.
- A contributor who needs the next allowed action and its expected result.
- A reviewer who must distinguish a claim from accepted or verified evidence.
- An agent that needs an exact, least-privilege route through the project.

## Invariants

- Repository history is evidence, not product intent.
- Observed, proposed, accepted, planned, actual, and verified facts remain
  distinct.
- Containment is finite and acyclic.
- Feedback has explicit budgets and terminal outcomes.
- Evolution may propose a successor; it cannot approve or activate itself.
- English and Russian public journeys have the same meaning and capabilities.

## Public surface

The public site contains Concept, Theory, Quickstart, Atlas, and Docs. English
is the first-visit default; Russian is a complete peer. The Atlas is a
projection of accepted data, never an independent source of truth.

## Brand commitments

The approved visual direction is **Signal Canvas**: a serious but informal
developer tool built from warm canvas, tactile paper modules, black ink
boundaries, and one mint primary signal. Cobalt explains, coral warns, and
yellow marks pending attention. The same system covers the whole site. It
avoids fantasy, role-playing-game decoration, generic dark dashboards,
decorative gradients, and effects that compete with the project map.

Claims must be supported by repository evidence, shipped behavior, or an
explicitly labeled proposal. Concord Loom has no approved testimonials,
performance benchmarks, or adoption claims.
